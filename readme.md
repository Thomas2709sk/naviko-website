# Naviko - Website

This repository contains the presentation website for Naviko, a mobile application designed to assist visually impaired people during outdoor navigation.

The website introduces the project, its main features, the technology behind Naviko, and its approach to accessibility and user safety.

---

## Project

Naviko is designed to provide additional assistance to visually impaired users by using the smartphone camera and artificial intelligence to detect elements in the user's surroundings.

The application can identify elements such as:

- Traffic lights
- Pedestrian crossings
- Vehicles
- Obstacles

Naviko provides feedback through voice and vibration alerts, while remaining an assistance tool and not a replacement for a white cane or guide dog.

The website serves as the main public presentation of the project.

---

## Website

The website presents:

- Project introduction
- Main features
- How Naviko works
- Download link
- FAQ
- Terms of Use
- Privacy Policy

The website is intentionally kept simple and accessible, with a focus on clarity, readability and accessibility.
